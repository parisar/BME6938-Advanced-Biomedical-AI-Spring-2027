# Proposal peer review

**Reviewing team:**

**Proposal reviewed:**

1. **Summary.** State the open problem and the proposed approach in two or three sentences.
2. **Strengths.** What is most convincing?
3. **Concerns.** Data, baseline, evaluation design, or feasibility issues, most serious first.
4. **Suggestions.** Concrete changes that would improve the study.
5. **Feasibility.** Can this be finished by the end of the term? If not, what should be cut?
